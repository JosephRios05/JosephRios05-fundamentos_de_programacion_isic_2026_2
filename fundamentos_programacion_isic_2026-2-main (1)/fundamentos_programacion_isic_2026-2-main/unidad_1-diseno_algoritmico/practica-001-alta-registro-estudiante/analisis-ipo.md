# Análisis Entrada-Proceso-Salida (IPO)

## 1. Planteamiento del Problema
El problema consiste en registrar la información básica de un estudiante de nuevo ingreso al sistema universitario. El programa debe capturar el número de control, nombre completo, promedio de preparatoria y estatus de documentos para posteriormente mostrar una ficha escolar con los datos registrados.

## 2. Tabla Entrada-Proceso-Salida

| Entradas | Procesos / Fórmulas | Salidas |
| Entradas                   | Procesos / Fórmulas  | Salidas              |
| -------------------------- | -------------------- | -------------------- |
| numeroControl (Entero)     | Capturar información | Ficha del estudiante |
| nombreCompleto (Cadena)    | Almacenar datos      | Número de control    |
| promedioPrepa (Real)       | Mostrar información  | Nombre completo      |
| estatusDocumentos (Lógico) | Imprimir resultados  | Promedio y estatus   |


## 3. Algoritmo en Lenguaje Natural
1. Inicio del algoritmo.
2. Declarar las variables numeroControl, nombreCompleto, promedioPrepa y estatusDocumentos.
3. Solicitar el número de control.
4. Solicitar el nombre completo.
5. Solicitar el promedio de preparatoria.
6. Solicitar el estatus de documentos.
7. Mostrar la ficha escolar.
8. Fin del algoritmo.
