# Práctica 01: Alta de Registro de Estudiante en el Sistema Universitario

## Objetivo

Capturar, almacenar e imprimir información de un estudiante utilizando variables de tipos de datos básicos en PSeInt.

## Descripción del problema

El Departamento de Servicios Escolares requiere un módulo para registrar estudiantes de nuevo ingreso. El sistema debe capturar datos de identificación sin utilizar estructuras condicionales.

## Entradas

- numeroControl (Entero)
- nombreCompleto (Cadena)
- promedioPrepa (Real)
- estatusDocumentos (Lógico)

## Proceso

1. Capturar los datos del estudiante.
2. Almacenar la información en variables.
3. Mostrar una ficha escolar con los datos registrados.

## Salidas

- Número de control
- Nombre completo
- Promedio de preparatoria
- Estatus de documentos

## Restricciones

- No utilizar estructuras condicionales.
- Respetar la convención camelCase en los identificadores.

## Conclusión

Se aplicó el uso de variables de tipo Entero, Cadena, Real y Lógico mediante una estructura secuencial en PSeInt.
